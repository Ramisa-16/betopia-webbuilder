# Betopia Web Builder - One Pager

## Product Summary
Betopia Web Builder is a desktop AI web-app builder that lets a user describe an application in natural language and turns that request into a complete working project. The product combines AI planning, code generation, file editing, live preview, terminal access, and project management in one native workspace.

## Problem
Building modern web apps usually requires switching between chat, editor, terminal, preview, and deployment tools. That creates context loss, slows iteration, and makes it hard to safely let AI make changes.

## Solution
Betopia Web Builder centralizes the build workflow in one Tauri-based desktop app:
- Chat to generate or modify a project
- Plan-build approval before the AI writes files
- Specialized agents for different tasks
- Inline code actions for fast refactoring and fixes
- Live preview with auto-refresh and runtime error tracking
- Integrated terminal, file explorer, and editor
- MCP support for external tools and workflows

## Core Capabilities
- Prompt-to-project generation
- Plan-first execution flow
- Multi-agent support: Coder, Architect, Reviewer, Security
- Custom agents with name, icon, and instructions
- Inline chat for explain, refactor, fix, and comment actions
- Auto-fix for preview runtime errors
- CodeMirror 6 editor with autocomplete and multi-tab editing
- File explorer with create, rename, delete, and git status badges
- Live preview with desktop, tablet, and mobile viewport modes
- Multiple terminal tabs and shell selection
- MCP server integration
- Multiple AI providers and model selection
- Publish and visibility controls
- Snippets and settings search
- Markdown preview and image/PDF viewing

## Target Users
- Developers building web projects faster
- Internal product teams and builders
- AI-assisted coding teams that need safer approval gates

## Value Proposition
Betopia Web Builder reduces tool switching and makes AI-assisted project creation safer, faster, and more transparent by combining planning, coding, previewing, and approvals in one app.

## Success Indicators
- Faster project scaffolding and iteration
- Fewer manual context switches between tools
- Successful plan approvals before file writes
- Reduced runtime debugging time through live preview and auto-fix
- Higher user retention across repeated project sessions
